# Kids-rewards / Recompensas

Quiero una aplicación web, para listar recompensas con niños según una serie de tareas que tienen que realizar.
Tiene que poder dar de alta y mantener tareas, pudiendo asignar puntos por cada tarea cumplida.
Tiene que poder dar de alta y mantener recompensas y el valor de las mismas.
La aplicación sólo pueden acceder padres, puesto que es para niños pequeños, pero servirá para mostrar de una forma gráfica las tareas y las recompensas.
Un padre cuando entre podrá ver a sus hijos, al acceder a su hijo podrá ver el tablón principal del mismo con las tareas y las recompensas. 
Descripción del tablón principal del hijo o hija:
  - Acceder a las tareas que ha hecho su hijo o hija
  - Acceder a las recompensas para canjearlas si el niño o niña tiene puntos suficientes.
  - Visualizar puntos totales del niño.
El tablón principal se debe compartir entre padres. El primero en entrar y configurarlo podrá compartirlo con el otro padre.

La aplicación será hecha en Next.js y Supabase. La autenticación vía email.
